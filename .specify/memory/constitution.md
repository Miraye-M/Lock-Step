# Remediation project principles

This workspace is Lockstep: ACC-to-ACS vulnerability remediation derived from
GitHub Spec Kit. Authoritative maintained guidance is in CONTRIBUTING.md,
AGENTS.md, docs/architecture.md, docs/harness.md and docs/agent-contracts.md.

Evidence precedes edits. Human approval binds a concrete plan. The worker owns
writes and gates; specialist agents return structured proposals. Require meaningful
before/after regression evidence, independent QA/code/security review and exact
commit/artifact/environment identity. Unknowns pause; reconcile external effects
before retry. Preserve user files, credentials and MIT attribution. Keep the demo
offline. Do not commit without the user's explicit consent.
